  How it works
  
Three steps. No boilerplate.

  

    
01
Pick a workflow
Browse by category. Each folder has a README, the workflow JSON and setup notes.

    
02
Import to n8n
Copy the JSON, open your canvas, and paste with Ctrl/Cmd + V. Nodes appear instantly.

    
03
Connect and run
Add your own credentials, test with sample data, then activate.
